## 四、关键缺口影响

**当前无 P0 缺口。** 兜底任务和系统日志已完成。

**缺口优先级排序：**

| 优先级 | 缺口 | 影响 |
|--------|------|------|
| P1 | Webhook 自动注册/注销 + 状态机 | 店铺管理需手动配置 webhook |
| P2 | 邮件管理完整筛选（店铺/类型/时间） | 人工排查效率受限 |
| P3 | `ticket_closed_notice` 触发逻辑 | 工单关闭后无法自动邮件提醒顾客 |
| P4 | 手机端适配完善（iOS 防放大、二次确认、错误态） | 顾客体验不稳定 |
| P5 | 复制/重新生成顾客链接能力 | 管理员无法从后台直接生成可发给顾客的新链接 |
| P6 | 自动触发 `agent_reply_notice` | 当前为管理员手动发送，未自动发送 |
