给管理员做“客户视角预览”功能，管理员从后台点按钮后，以管理员身份打开一个只读预览页面，而不是复用顾客邮件里的真实访问链接。

推荐方案：管理员预览链接

后台邮件管理里显示：

工单客户端链接：
https://support.yourdomain.com/ticket/preview/T202605120001

或者：

/admin/preview/ticket/T202605120001

这个链接只允许已登录客服 / 管理员访问。

流程：

管理员登录 /admin
  ↓
进入邮件详情 / 工单详情
  ↓
点击“预览顾客页面”
  ↓
后端校验管理员 session
  ↓
加载对应订单 / 工单数据
  ↓
用顾客端页面样式渲染
  ↓
但不允许真正提交 / 回复 / 关闭

也就是说，管理员可以看到顾客看到的页面效果，但不会拿到顾客 token。

为什么不要直接展示完整顾客链接

顾客链接里的 token 本质上是访问凭证。只要有人拿到完整链接，就可以：

查看顾客订单信息
查看工单消息
以顾客身份继续回复
关闭工单

所以后台长期保存或展示完整 token 链接有风险。

实现方式
1. 顾客真实链接继续这样

邮件里真实发给顾客：

https://support.yourdomain.com/ticket?t=bt_xxxxx

或工单创建后：

https://support.yourdomain.com/ticket?t=ta_xxxxx

数据库里只存：

token_hash
purpose
order_id
public_ticket_no
customer_email
expires_at

不长期保存原始 token。

2. 后台新增预览接口

新增接口：

GET /api/admin/tickets/:publicTicketNo/customer-preview

或者针对付款后未建工单的订单：

GET /api/admin/orders/:storeSubdomain/:orderId/customer-preview

后端要求：

1. 必须管理员已登录
2. 根据 publicTicketNo 或 orderId 查数据库
3. 返回顾客端页面需要的数据
4. 标记 preview_mode = true

返回示例：

{
  "ok": true,
  "preview_mode": true,
  "order": {
    "store_name": "ThinkPro",
    "order_number": "#897542",
    "paid_at": "2026-05-11T10:30:00Z",
    "payment_method": "Shoplazza Payments-Card",
    "card_last4": "4690",
    "order_amount": "85.88",
    "order_currency": "USD",
    "items": []
  },
  "ticket": {
    "public_ticket_no": "T202605120001",
    "status": "open"
  },
  "messages": []
}
3. 前端共用顾客页面组件

如果你用原生 HTML，也可以这样做：

/ticket?t=真实顾客token
  给顾客用

/admin/ticket-preview.html?ticket=T202605120001
  给管理员预览用

两个页面可以共用一套渲染函数：

renderOrder()
renderTicket()
renderMessages()

但预览模式下禁用操作按钮：

提交工单按钮：隐藏
回复框：禁用
关闭工单按钮：禁用

页面上显示一个明显提示：

管理员预览模式：此页面仅用于查看顾客端展示效果，不能代表顾客操作。
邮件管理里的“工单客户端链接”怎么显示

后台可以显示脱敏链接：

https://support.yourdomain.com/ticket?t=bt_abcd...wxyz

旁边放两个按钮：

预览顾客页面
重新生成顾客链接
“预览顾客页面”

不使用顾客 token，走管理员预览接口。

“重新生成顾客链接”

只有确实需要重新发给顾客时才用：

1. 创建新的 support_access_tokens 记录
2. 生成新的 bt_ 或 ta_ token
3. 可选择立即补发邮件
4. 旧 token 可保留或撤销
邮件内容快照怎么处理

邮件内容快照里仍然不建议保存完整 token。

可以保存成：

https://support.yourdomain.com/ticket?t=bt_abcd...wxyz

或者保存模板变量：

{
  "store_name": "ThinkPro",
  "order_number": "#897542",
  "paid_at": "2026-05-11T10:30:00Z",
  "payment_method": "Shoplazza Payments-Card",
  "card_last4": "4690",
  "client_link_masked": "https://support.yourdomain.com/ticket?t=bt_abcd...wxyz"
}

补发时不要复用旧 token，重新生成新 token 后重新渲染邮件。
